# Crescimento e Monetização

## Estratégia de crescimento

### Fase 0 — ativação da comunidade existente (maior vantagem competitiva)
- O grupo de WhatsApp já é uma base de usuários engajada e confiante — é o ativo mais valioso
  que a plataforma tem no dia 1. Prioridade: onboarding sem fricção para esse grupo específico
  (convite pessoal, não campanha genérica).
- "Semana de migração": cada membro publica pelo menos 1 poema já existente, com ajuda ativa
  de quem construiu a plataforma tirando dúvidas no próprio grupo.

### Aquisição
- **Compartilhamento como canal principal:** cada poema compartilhado no WhatsApp/Instagram
  com uma boa imagem OG *é* o anúncio — investir pesado na qualidade do preview de
  compartilhamento antes de qualquer investimento em ads.
- **SEO de cauda longa:** poemas indexados pelo Google captam buscas como "poema sobre saudade
  curto", "poema para postar no story" — tráfego orgânico gratuito e recorrente.
- **Cross-posting assistido para Instagram:** gerar automaticamente uma imagem "postável" do
  poema (formato story/feed) com o link da plataforma no rodapé — o autor continua publicando
  no Instagram, mas sempre linkando de volta para o "lar" do poema.
- **Parcerias com contas literárias/poesia no Instagram** para descoberta de novos autores.

### Retenção
- **Estatísticas de leitura** (algo que Instagram não entrega bem) como motivo recorrente de
  voltar à plataforma.
- **Newsletter "poema da semana"** — cria hábito de retorno tanto para autores (querem
  aparecer) quanto para leitores.
- **Notificações discretas** (V2) de curtidas/comentários/novos seguidores — sem exagero, no
  espírito "silêncio visual" da marca.

### Descoberta orgânica dentro da plataforma
- Páginas editoriais (`/descubra`, `/em-alta`, `/sentimentos/[slug]`) fazem o papel de
  "curadoria de livraria" — reforça a identidade de biblioteca, evita depender de um
  algoritmo de engajamento.

## Modelos de monetização

| Modelo | Quando | Como funciona |
|---|---|---|
| **Comissão sobre vendas do marketplace** | Fase 5+ | Plataforma retém % (ex.: 10-15%) de cada venda via Stripe Connect split |
| **Assinatura "Autor Pro"** | Fase 6 | Recursos premium: estatísticas avançadas, remoção de marca d'água em imagens OG, domínio próprio (`autor.com` → perfil), destaque em descoberta |
| **Conteúdo/autores patrocinados** | Fase 6+ | Espaços editoriais de "destaque" vendidos com transparência (marcado como patrocinado), nunca comprometendo a curadoria orgânica |
| **Parcerias de print-on-demand** | Fase 5-6 | Reduz risco de estoque para autores venderem livros físicos/produtos sem gerenciar fulfillment |
| **Eventos/oficinas literárias (online)** | Fase 6+ (oportunidade, não core) | Venda de ingressos para saraus/oficinas via a própria plataforma |

## Princípios de monetização

1. **Nunca cobrar do leitor para ler.** A leitura é sempre gratuita — a receita vem do autor
   que vende algo opcional, não de acesso ao conteúdo.
2. **A plataforma só ganha quando o autor ganha** (modelo de comissão) — alinha incentivos e é
   mais fácil de justificar para uma comunidade que começou como um grupo colaborativo.
3. **Transparência de preço e comissão** — autores devem ver claramente quanto ficou de comissão
   em cada venda.
