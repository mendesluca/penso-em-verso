# Backlog Organizado (Épicos → Histórias)

Formato: `[ ] Como <persona>, quero <ação>, para <benefício>. (Prioridade/Esforço)`

## Épico: Autenticação
- [ ] Como visitante, quero me cadastrar com e-mail/senha, para criar meu perfil. (🔴/●●)
- [ ] Como visitante, quero entrar com Google, para não precisar criar outra senha. (🔴/●●)
- [ ] Como usuário, quero recuperar minha senha por e-mail, para não perder acesso à conta. (🔴/●)
- [ ] Como usuário, quero confirmar meu e-mail, para validar minha conta. (🔴/●)

## Épico: Perfil
- [ ] Como autor, quero escolher um `@usuario` único, para ter uma URL memorável. (🔴/●)
- [ ] Como autor, quero adicionar foto, banner, bio e redes sociais, para me apresentar. (🔴/●)
- [ ] Como autor, quero ver meu perfil como visitantes o veem (preview). (🟡/●)
- [ ] Como leitor, quero ver a lista de poemas de um autor, para conhecer sua obra. (🔴/●)

## Épico: Editor e publicação
- [ ] Como autor, quero escrever um poema com título e conteúdo, para registrá-lo. (🔴/●●)
- [ ] Como autor, quero que meu rascunho seja salvo automaticamente, para não perder texto. (🔴/●●)
- [ ] Como autor, quero adicionar categoria, tags e capa opcional, para organizar/enriquecer. (🟡/●)
- [ ] Como autor, quero publicar um poema e receber sua URL definitiva, para compartilhar. (🔴/●)
- [ ] Como autor, quero editar um poema já publicado, para corrigir ou melhorar. (🔴/●)
- [ ] Como autor, quero excluir um poema, para remover algo que não represento mais. (🟡/●)

## Épico: Leitura e engajamento
- [ ] Como leitor, quero ler um poema sem precisar de login. (🔴/●)
- [ ] Como leitor, quero ver tempo estimado de leitura e data de publicação. (🟡/●)
- [ ] Como leitor, quero curtir um poema. (🔴/●)
- [ ] Como leitor, quero favoritar um poema para reler depois. (🔴/●)
- [ ] Como leitor, quero comentar em um poema. (🟡/●)
- [ ] Como leitor, quero compartilhar um poema com uma boa prévia visual no WhatsApp/Instagram. (🔴/●●)

## Épico: Coleções
- [ ] Como autor, quero agrupar poemas em uma coleção temática. (🟡/●●)
- [ ] Como autor, quero decidir se uma coleção é pública ou privada. (🟡/●)
- [ ] Como leitor, quero navegar por uma coleção pública como se fosse um pequeno livro. (🟢/●)

## Épico: Busca e descoberta
- [ ] Como leitor, quero buscar por título, autor, palavra-chave, categoria ou tag. (🔴/●●)
- [ ] Como leitor, quero ver "poemas do dia" e "em alta". (🟡/●●)
- [ ] Como leitor, quero descobrir poemas por sentimento (saudade, amor, melancolia...). (🟡/●●)
- [ ] Como leitor, quero descobrir novos autores recém-chegados. (🟢/●)

## Épico: Comunidade (V2)
- [ ] Como leitor, quero seguir um autor, para acompanhar suas novas publicações. (🔴/●)
- [ ] Como usuário, quero um feed apenas com quem sigo. (🔴/●●)
- [ ] Como usuário, quero receber notificações de curtida/comentário/novo seguidor. (🔴/●●●)
- [ ] Como leitor, quero responder a um comentário. (🟡/●●)

## Épico: Estatísticas
- [ ] Como autor, quero ver quantas visualizações e leituras completas meus poemas têm. (🟡/●●)
- [ ] Como autor, quero ver curtidas, favoritos e compartilhamentos agregados. (🟡/●)
- [ ] Como autor, quero ver o crescimento de seguidores ao longo do tempo. (🟢/●●)
- [ ] Como autor, quero saber quais são meus poemas mais populares. (🟡/●)

## Épico: Marketplace
- [ ] Como autor, quero cadastrar produtos (ebook, livro físico, camiseta etc.) na minha loja. (🔴/●●)
- [ ] Como autor, quero conectar minha conta ao Stripe para receber pagamentos. (🔴/●●●)
- [ ] Como leitor, quero comprar um produto de um autor que admiro. (🔴/●●●)
- [ ] Como comprador, quero baixar meu eBook após a compra. (🔴/●●)
- [ ] Como autor, quero ver minhas vendas em um painel simples. (🟡/●●)

## Épico: SEO
- [ ] Como plataforma, preciso que cada poema tenha metadata, OG e URL amigável, para ranquear no Google. (🔴/●)
- [ ] Como plataforma, preciso de sitemap.xml automático. (🔴/●)
- [ ] Como plataforma, preciso de imagens OG geradas dinamicamente por poema. (🟡/●●)
